# 🤖 منصة صانع البوتات V2

## الموجود
- إنشاء بوتات من ثلاثة قوالب.
- إدارة القوالب.
- إحصائيات المنصة.
- إحصائيات كل بوت.
- إذاعة لمستخدمي منصة الصانع أو مستخدمي بوت محدد.
- اشتراك إجباري للقنوات والمجموعات.
- بوت تواصل.
- بوت زخرفة.
- بوت إدارة مجموعات: ترحيب، ردود، حماية من الروابط، ألعاب بسيطة وأوامر إدارية.
- تخزين SQLite عبر node:sqlite.
- Long Polling مع حذف Webhook قبل التشغيل.

## متطلبات التشغيل
Node.js 22+، ويفضل Node.js 26.

ضع BOT_TOKEN و OWNER_ID في متغيرات البيئة. لا تضع .env في GitHub.
