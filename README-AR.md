# 🤖 منصة صانع البوتات

منصة Node.js + grammY لإنشاء وتشغيل بوتات Telegram متعددة من بوت رئيسي واحد.

## المزايا
- إنشاء بوتات مستقلة من 3 قوالب.
- 📩 بوت تواصل احترافي: رسائل خاصة بكل مالك، بيانات المستخدم، رد مباشر، حظر.
- ✨ بوت زخرفة.
- 🛡️ إدارة مجموعات أساسية: قفل/فتح، حظر، كتم، حماية روابط، قوانين وأوامر.
- 🔒 اشتراك إجباري عام.
- 📢 إذاعة عامة.
- 📊 إحصائيات المنصة وإحصائيات كل مالك.
- استعادة وتشغيل البوتات المنشأة تلقائيًا بعد إعادة تشغيل الاستضافة.
- Node.js 26 و `node:sqlite` بدون native bindings.

## التشغيل
ضع المتغيرات:
- `BOT_TOKEN`
- `OWNER_ID`
- `DB_PATH=/data/bot-maker.sqlite`

ثم:

```bash
npm start
```

لا تضع أي Token في GitHub.
