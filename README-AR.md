# 🤖 منصة صانع البوتات

منصة Telegram متعددة البوتات مبنية بـ Node.js 26 + grammY + SQLite المدمج (`node:sqlite`).

## المزايا الحالية

### 🏭 إنشاء البوتات
- 3 قوالب مستقلة: 🛡️ إدارة المجموعات، 📩 تواصل، ✨ زخرفة.
- كل بوت مصنوع مستقل بقاعدة مستخدمين وإعدادات خاصة بمالكه.
- خطوات إنشاء احترافية مع رابط BotFather مباشر.
- يطلب اسم البوت ثم Token، ويتحقق من Token ويبدأ البوت تلقائيًا.

### 📩 بوت التواصل
- المستخدمون لكل بوت منفصلون عن بقية البوتات.
- تصل الرسائل إلى مالك ذلك البوت فقط.
- عرض اسم المستخدم وUsername وTelegram ID ونوع الرسالة.
- نسخ الرسائل والوسائط إلى المالك.
- زر رد مباشر وزر حظر.
- رد المالك يعود للمستخدم من نفس بوت التواصل.

### ✨ بوت الزخرفة
- 10 نتائج لكل اسم/عبارة.
- أولوية للزخارف العربية، مع رموز وأقواس وتطويل وتشكيلات.
- دعم زخارف Unicode للإنجليزية.
- زر مستقل لكل نتيجة وزر تحديث للحصول على 10 زخارف جديدة.

### 🛡️ إدارة المجموعات
- رسالة ترحيب قابلة للتخصيص.
- `1` أو `/1` لإظهار معلومات المستخدم مع صورته عند توفرها.
- `كت` أو `/كت` لسؤال شخصي عشوائي ثم رد تفاعلي.
- ردود تلقائية للكلمات والعبارات العراقية الشائعة.
- قفل/فتح، حظر، كتم، إلغاء الكتم، حماية الروابط.
- قوانين وأوامر مخصصة محفوظة لكل بوت.

### 🔒 الاشتراك الإجباري
- لوحة المالك تسمح بإضافة عدة قنوات ومجموعات.
- لكل اشتراك اسم وChat ID ورابط دعوة.
- تظهر للمستخدم أزرار الاشتراك وزر تحقق.
- يمكن تعطيل الاشتراكات من لوحة المالك.

### 📢 الإذاعة العامة
- من لوحة المالك زر إذاعة عامة.
- يدعم النص والصور والفيديو والملفات والروابط والرسائل المنسوخة.
- يستهدف مستخدمي منصة صانع البوتات ومستخدمي البوتات المصنوعة.
- عند الحاجة يتم الإرسال من البوت الذي سبق للمستخدم استخدامه، لأن Telegram لا يسمح للبوت الرئيسي بمراسلة مستخدم لم يبدأه.

## متغيرات البيئة
- `BOT_TOKEN` توكن بوت المنصة الرئيسي.
- `OWNER_ID` رقم Telegram ID للمالك.
- `DB_PATH=/data/bot-maker.sqlite`

## التشغيل

```bash
npm install

```
